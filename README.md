# CMP2103
# Introduction to Object-Oriented Programming (OOP) with C++

Welcome to the **Introduction to Object-Oriented Programming (OOP) with C++** tutorial.

This tutorial introduces the fundamental concepts of Object-Oriented Programming using **C++**, with a practical, hands-on approach. It is designed to help beginners understand how to structure programs around objects, classes, and reusable components.

## Learning Objectives
By the end of this course, you should be able to:

- Understand fundamentals of Object Oriented Programming
- Understand the fundamental programming concepts
- Understand key useful techniques
- Basic standard C++ facilities
- Write good code

## Prerequisites
- Interest and ability to learn and create interesting stuff!

## Note
- This is an introductory course to C++, and students are expected to study more advanced courses on the topic. The examples listed are not meant to hardcode your thinking; rather, they are intended to facilitate good thought processes as you learn to write better programs.

## Assignments
### Documentation Requirement

For every assignment, include a corresponding `.md` file that documents your solution.

The `.md` file must explain:

* OOP Concepts Used — Identify and explain the object-oriented programming concepts applied in your solution.
* Algorithm — Describe the algorithm and the main steps used to solve the problem.
* Possible Error Points — Identify potential errors, edge cases, or common mistakes that may occur when implementing or running the program.

### Submission Structure

Each assignment should therefore contain both the source code and its documentation. Give the .md file name as the program filename e.g matrix.cpp and matrix.md
Ensure that your code and documentation are committed and pushed to your solutions repository.

## AI Policy
This assignmenta are intended to assess your individual understanding of C++ and OOP. Students should write and debug their own solutions without using generative AI tools to generate, modify, or explain the assignment solution. You may use course notes, textbooks, official C++ documentation, and your own previously written code. You must be able to explain and modify any code you submit.
